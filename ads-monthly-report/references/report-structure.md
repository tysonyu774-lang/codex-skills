# Report Structure

Default language: Chinese. Keep platform/app names in English.

## HTML Page Sections

1. Header
   - Client/report title
   - Date range
   - Source files
   - Prepared date

2. Executive Summary
   - 3-5 bullets.
   - State the main outcome, not just numbers.
   - Include one clear next-month priority.

3. KPI Overview
   - Spend
   - Revenue
   - Conversions
   - CPA
   - ROAS
   - CTR
   - Optional CPC/CPM/CVR

4. Platform Comparison
   - Show Meta vs Google if both exist.
   - Mention each platform's role: traffic acquisition, conversion capture, retargeting, brand reach, Shopping/Search intent.

5. Campaign Analysis
   - Ranked table.
   - Include spend share, conversions, CPA/ROAS, CTR, and recommendation.
   - Identify budget scale/cut actions.

6. Creative/Material Analysis
   - Top creative winners.
   - Underperforming creative.
   - Creative pattern insights: offer, hook, product visibility, format, landing page alignment.
   - Next creative tests.

7. Problems and Risks
   - Tracking gaps.
   - High spend low conversion.
   - Fatigue.
   - Keyword/intent mismatch.
   - Landing page or product page friction.

8. Next Month Plan
   - Budget moves.
   - Campaign structure changes.
   - Creative production list.
   - Tracking/data fixes.
   - Testing roadmap.

9. Source Notes
   - Files used.
   - Date range.
   - Missing fields or assumptions.

## Visual Style

Use a polished dashboard/report layout:

- Light background.
- Dark text.
- KPI cards.
- Tables with subtle borders.
- Green for strong results, amber for watch, red for weak.
- No decorative clutter.
- Responsive layout for laptop and mobile.

## Recommendation Labels

- `Scale`: strong conversion quality and enough volume.
- `Keep Testing`: promising but not enough volume.
- `Refresh`: performance declining or creative fatigue.
- `Pause`: high spend with poor CPA/ROAS.
- `Needs Data`: too little spend/conversion data.

## Caveat Language

Use direct language:

- "本报告缺少 revenue/conversion value，因此 ROAS 只能留空，重点以 CPA 和转化量判断。"
- "该素材点击率高但转化率低，说明前端吸引力不错，但落地页/产品承诺可能不匹配。"
- "该系列花费占比高，但转化贡献低，建议下月先降预算并重测受众或素材。"
